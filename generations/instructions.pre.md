# Main Page Purpose
The page captures user data using the hook of discovering whether their home or business is viable for solar energy installation, offering a free visit.

Example text:

Many people don’t know if their home or business is compatible with solar installations. We’ll check for you — free and with no obligation!

Call to Action:

"Leave us some basic info to get a free visit"

Information to Collect:
Postal code

Name (required)

Phone number (required)

Location (required) — [address, city/town, postal code, house/apartment number]

User Flow:
To make the process smoother and less overwhelming, it's suggested to break it down into 3 steps so the user doesn’t see the entire form all at once.

Step 1
The user enters Postal Code and clicks Next

Step 2
The user enters Name and Phone Number, and checks a box to allow their data to be used for commercial purposes

Step 3
The user can enter their Address.

Step 4
A confirmation screen congratulates them on starting their journey toward solar energy. It includes a message explaining the next step (e.g. “We’ll call you soon from Ibergenil to schedule your visit”)

END OF FLOW

Additional Sections
The portal can include extra sections to help the user feel more confident. Here are some ideas:

“Happy Customers Gallery” Section
This section shows a gallery of photos or videos from previous Ibergenil installations, giving the user social proof of the company’s reliability.
Example tagline: “Your neighbors are already switching to solar energy”

“Quick Quiz” Section
This section asks a few quick questions to highlight the benefits of solar installations for the user.

Note: Every section should include a Call to Action that brings the user back to the main flow to leave their info for a free visit.

# Graphical style
Picture a sleek, modern website with impactful and engaging design for solar panel installations that greets visitors with a full-width hero section featuring a high-res image of solar panels under a blue sky, overlaid with a bold H1 tagline in Montserrat SemiBold, colored in #0e1b54. This is complemented by a warm #fcb12b call-to-action (CTA) button with sharp corners and a subtle shadow for elevation. The overall layout breathes—thanks to generous padding and whitespace—with a 12-column grid system that ensures clarity and focus. The background remains light with #f6f6f6 used throughout for sections and page backgrounds, giving contrast to sharp edge cards and content blocks outlined in soft #ef5a3c or #0e1b54 text for hierarchy.

Navigation is sticky and minimal, with a transparent background that becomes #0e1b54 on scroll, and buttons in #f7931e with hover states that invert colors or gently animate. Icons (solar, battery, efficiency, etc.) are minimal and line-based, supporting the content without crowding it. Forms use full-width inputs with rounded edges, light grey backgrounds, and accent-colored borders when focused. Animated microinteractions (like a subtle fade or slide-in). Sticky “Call Now” buttons persist on mobile for frictionless conversion. Clean. Trustworthy. Sunny vibes all the way.
